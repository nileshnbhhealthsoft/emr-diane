# Employer Module of OpenEMR

This module is to help a practice manage the employer information for patients.
Employers are tracked per patient and linked to the patient demographics so that
employment history, occupation and industry can be maintained. The module
provides the tools necessary to see what employers a patient has had in the
system.

## Getting Started

When you install this module, it will use the existing `employer_data` table
that ships with OpenEMR. The module will grab the employers that have been
stored in the system and display them so you can review the employment history
for a patient. The system will allow the management of employer records
including name, address, employment dates, occupation and industry.
